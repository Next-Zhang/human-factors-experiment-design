# 人因实验设计 Skill

把一条自然语言描述的人因研究问题转化为一套可执行、可审查的实验方案。也可用于审查已有方案，找出会影响执行或结果解释的缺口。

适用于比较界面、设备、工作流程或人机协作方式对人的影响，例如任务完成表现、工作负荷、错误和恢复能力。

## 输入与输出

**输入**至少包含一条研究问题。已知的目标人群、使用情境、现有方案、可用设备、时间预算和招募限制，可以一并提供。

**输出**是一套实验方案，按八步展开。

1. 界定问题、使用情境与研究范围
2. 定义假设与结果判断规则
3. 明确实验条件、指标与记录字段
4. 选择实验设计并控制混杂
5. 规划参与者招募、纳排标准与样本量
6. 编写任务、材料、主持脚本与记录表
7. 预先拟定数据处理与分析计划
8. 设计预实验、通过判据与复测规则

每一步记录交付物版本、验收判据、证据与状态。Skill 会列出仍需确认的事项以及它们对方案的影响。研究负责人确认任务是否具有代表性、什么结果值得改变设计，并负责参与者保护、招募、试跑与正式实施。

## 安装到 Codex 项目

1. 下载本仓库的 [SKILL.md](SKILL.md)。
2. 将它保存到你要使用该 skill 的项目目录，文件结构如下。

```text
你的项目/
└── .agents/
    └── skills/
        └── human-factors-experiment-design/
            └── SKILL.md
```

3. 在 Codex 中打开该项目。若输入 `$` 后未看到该 skill，可以重启 Codex 并重新打开项目。

## 调用方法

在 Codex 输入框中使用 `$human-factors-experiment-design`，随后写出你的研究问题。可附上已有材料或补充约束。

```text
$human-factors-experiment-design
研究问题：在自助借书终端上，图文引导相比纯文字引导，能否减少首次使用者的操作错误？
目标人群：第一次使用该终端的读者。
资源：可以制作两个可点击原型，单次测试控制在 20 分钟以内。
请给出完整方案，并标出需要我确认的研究决策。
```

如果已有草案，可以在调用时附上草案，并让 skill 按八步标出缺失的交付物、核验证据和需要修订的地方。
